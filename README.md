# illililiiililii의 메신저 (알파 V 0.0.2)

그냥 스펙 쌓기 용으로 만들어 본 메신저입니다. 별 기능은 없습니다. <br>
평범하게 로그인/회원가입 기능과 메세지 전송/수신, API를 활용한 AI 비서 호출, <br>
코드 뷰어, 파일 첨부 기타 등등 기능을 만들어 보았습니다. 글 솜씨가 좋지 않아서 많이는 못 적겠네요.
